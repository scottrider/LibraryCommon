## 🛠️ Available Tools and Commands

### **Quick Visual Capture**
```bash
npm run visual:current     # Capture current state
npm run visual:baseline    # Capture baseline (before changes)
npm run visual:report      # Generate visual regression report
npm run visual:full        # Capture + generate report
```

### **Advanced Testing**
```bash
npm run test:visual        # Run full Playwright test suite
npm run test:visual:headed # Run with browser UI visible
```

### **Manual Commands**
```bash
node visual-capture.js baseline   # Manual baseline capture
node visual-capture.js current    # Manual current capture
node visual-capture.js report     # Manual report generation
```
