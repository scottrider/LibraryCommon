# Node.js Project Configuration

## External Dependencies Strategy
- Global Node.js: v22.11.0
- Project-specific dependencies via package.json
- Local configuration files for project settings

## Local Settings Files:
- .nvmrc - Node version specification
- package.json - Project dependencies and scripts
- .npmrc - npm configuration (if needed)
- jsconfig.json - VS Code JavaScript project settings

## Benefits:
- ✅ Shared Node.js installation across projects
- ✅ Project-specific dependency management
- ✅ Version control for project requirements
- ✅ Clean separation of global vs local resources
